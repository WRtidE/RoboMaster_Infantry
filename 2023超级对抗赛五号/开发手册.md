## 四、CAN 总线通信协议

### 4.1 总线参数

```
波特率: 1 Mbps
Prescaler: 3
BS1: 10 TQ, BS2: 3 TQ
SJW: 1 TQ
```

### 4.2 CAN ID 分配表

#### CAN1 — 电机控制总线

| CAN ID      | 方向     | 内容                          | 周期   |
| ----------- | -------- | ----------------------------- | ------ |
| `0x200`     | 接收     | 底盘电机1-4 反馈 (3508)       | 1ms    |
| `0x1FF`     | 发送     | 底盘电机1-4 控制电流          | 1ms    |
| `0x204`     | 接收     | 拨弹电机反馈 (3508)           | 1ms    |
| `0x205`     | 接收     | Yaw 电机反馈 (6020)           | 1ms    |
| `0x206`     | 接收     | Pitch 电机反馈 (6020)         | 1ms    |
| `0x2FF`     | 发送     | 6020 电机控制                 | 1ms    |

#### CAN2 — 板间通信总线

| CAN ID      | 方向            | 内容                          | 周期   |
| ----------- | --------------- | ----------------------------- | ------ |
| `0x300`     | 双向            | 遥控器通道 0~3                | 10ms   |
| `0x301`     | 双向            | 遥控器通道 4 + 开关           | 10ms   |
| `0x302`     | 云台→底盘       | IMU 姿态数据 (Yaw/Pitch/Roll) | 1ms    |
| `0x305`     | 底盘→云台       | 裁判系统数据 (热量/等级)      | 10ms   |
| `0x210`     | 接收            | 超级电容数据                  | 10ms   |
| `0x55`      | 发送            | 小PC 目标偏角                 | 10ms   |

### 4.3 3508 电机 CAN 数据格式

**反馈帧 (0x200 + ID)**
```
字节0-1: 转子角度 (0~8191, 对应 0~360°)
字节2-3: 转子转速 (RPM, int16)
字节4-5: 实际转矩电流 (int16)
字节6:   电机温度 (°C)
```

**控制帧 (0x1FF)**
```
字节0-1: 电机1 电流 (int16, -16384 ~ +16384)
字节2-3: 电机2 电流
字节4-5: 电机3 电流
字节6-7: 电机4 电流
```

### 4.4 6020 电机 CAN 数据格式

**控制帧 (0x2FF)**
```
字节0-1: 电压值 (int16, -30000 ~ +30000)
```

### 6.3 AHRS 姿态解算 (Mahony 算法)

```c
// 参数
float twoKp = 0.5f;     // 比例增益
float twoKi = 0.0f;     // 积分增益 (禁用)

// 输入: 陀螺仪 (rad/s), 加速度计 (G), 磁力计 (μT)
// 输出: q0, q1, q2, q3 (四元数)

// 欧拉角转换
roll  = atan2(2*(q0*q1 + q2*q3), 1 - 2*(q1^2 + q2^2));
pitch = asin(2*(q0*q2 - q3*q1));
yaw   = atan2(2*(q0*q3 + q1*q2), 1 - 2*(q2^2 + q3^2));
```

## 九、控制算法详解

### 9.1 PID 控制算法

#### 位置式 PID

```
error(k) = target - current
Pout = Kp * error(k)
Iout += Ki * error(k)    (带积分限幅)
Dout = Kd * (error(k) - error(k-1))
out  = Pout + Iout + Dout (带输出限幅)
```

#### 云台角度环特殊处理 (处理 ±180° 跳变)

```c
// 圆周角度误差归一化
if(err > 180)  err -= 360;
if(err < -180) err += 360;
```

#### 积分分离

```c
// 当误差较大时，关闭积分项防止积分饱和
if(fabs(error) > threshold)
    Iout = 0;
```

### 9.2 Kalman 滤波器 (IMU)

```c
// 一维 Kalman 用于角度融合
float Q_angle    = 0.003f;   // 角度过程噪声
float Q_gyro_bias = 0.004f;  // 陀螺仪偏差噪声
float R_measure  = 0.3f;     // 加速度计测量噪声
float dt         = 0.001f;   // 时间步长 (1ms)

// 预测步骤
angle += (gyro - bias) * dt;

// 更新步骤
// 用加速度计角度修正预测值
```

### 9.3 互补滤波器

```c
// 快速融合加速度计与陀螺仪
angle = K * angle_accel + (1-K) * (angle + gyro * dt);
// K 通常取 0.02
```

## 十、底盘运动学

### 10.1 麦克纳姆轮模型

```
        前方
    ┌──────────┐
    │  3    4  │
    │  2    1  │
    └──────────┘

Vx: 前进/后退
Vy: 左移/右移
Wz: 旋转 (逆时针为正)
```

### 10.2 遥控器 → 速度矢量

```c
// 计算极坐标
Vx_raw = ch[2] - 1024;   // X 分量
Vy_raw = ch[3] - 1024;   // Y 分量
Wz_raw = ch[4] - 1024;   // 旋转分量

r = sqrt(Vx_raw^2 + Vy_raw^2);
sin_sita = Vy_raw / r;
cos_sita = Vx_raw / r;

// 归一化到电机速度范围
target_v    = (r / 660)    * 9158;  // 平移速度
target_curl = (|Wz_raw| / 660) * 9158;  // 旋转速度
```

### 10.3 四轮速度合成

```c
// 麦克纳姆轮逆运动学
motor[0] =  0.707 * target_v * (sin_sita + cos_sita) / 2 - target_curl / 2;  // LF
motor[1] = -0.707 * target_v * (sin_sita - cos_sita) / 2 - target_curl / 2;  // RF
motor[2] =  0.707 * target_v * (sin_sita - cos_sita) / 2 - target_curl / 2;  // RB
motor[3] = -0.707 * target_v * (sin_sita + cos_sita) / 2 - target_curl / 2;  // LB
```

### 10.4 速度限幅

```c
// 等比缩放：防止任一电机超速
void Motor_Speed_limiting(int16_t *motor_speed, int16_t limit) {
    int16_t max = 0;
    for(int i = 0; i < 4; i++) {
        int16_t abs_v = motor_speed[i] > 0 ? motor_speed[i] : -motor_speed[i];
        if(abs_v > max) max = abs_v;
    }
    if(max > limit) {
        float rate = (float)limit / max;
        for(int i = 0; i < 4; i++)
            motor_speed[i] *= rate;
    }
}
```

## 十三、常见问题

### Q1: 电机不转？
- 检查 CAN 总线波特率是否匹配 (1Mbps)
- 确认电调 ID 与代码中 CAN ID 一致
- 检查电机供电 (24V)

### Q2: IMU 数据异常？
- 确认 SPI 引脚连接正确
- 运行 `IMU_offset_cali()` 重新标定
- 检查 IMU 温度是否达到 40°C

### Q3: 遥控器无响应？
- 检查 USART3 波特率 (115200)
- 确认接收器信号线连接
- 检查 SBUS 协议解析是否正确

### Q4: 底盘运动方向不对？
- 检查电机编号与接线顺序 (1~4)
- 验证麦克纳姆轮安装方向
- 调整速度合成公式中的符号

### Q5: PID 震荡/发散？
- 降低 Kp，逐步增加
- 检查编码器反馈是否正常
- 增大输出限幅保护

### Q6: 文件打开乱码？
- 项目源文件使用 **GBK** 编码
- VS Code: 状态栏点击编码 → "通过编码重新打开" → 选择 GBK
- Keil: 自动识别 GBK
