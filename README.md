## 🛠 硬件平台

| 项目       | 型号/规格                  |
| ---------- | -------------------------- |
| **主控**   | STM32F407xx (ARM Cortex-M4) |
| **主频**   | 168 MHz                    |
| **RTOS**   | FreeRTOS (CMSIS-OS 接口)    |
| **IDE**    | Keil MDK-ARM (µVision)     |
| **配置工具** | STM32CubeMX (.ioc)       |

### 传感器

| 传感器     | 型号    | 接口 | 用途              |
| ---------- | ------- | ---- | ----------------- |
| 6轴 IMU    | BMI088  | SPI  | 加速度 + 陀螺仪   |
| 3轴磁力计  | IST8310 | I2C  | 地磁航向参考      |
| 电机编码器 | -       | CAN  | 电机角度/转速反馈 |

### 电机

| 电机       | 用途           | 数量 |
| ---------- | -------------- | ---- |
| 3508 电机  | 底盘驱动/拨弹  | 4+2  |
| 6020 电机  | 云台 Yaw 轴    | 1    |

## 🧱 软件架构

### 分层设计

```
┌─────────────────────────────┐
│       Task（任务层）          │  ← FreeRTOS 任务
├─────────────────────────────┤
│    AlgorithmLayer（算法层）   │  ← PID 控制、IMU 解算
├─────────────────────────────┤
│     PotocaLayer（协议层）     │  ← CAN 通信协议
├─────────────────────────────┤
│     DriverLayer（驱动层）     │  ← CAN/UART/SPI/I2C 驱动
├─────────────────────────────┤
│  STM32 HAL / CMSIS / FreeRTOS │  ← 底层库
└─────────────────────────────┘
```

### RTOS 任务结构（底盘板）

| 任务         | 功能                 | 说明                              |
| ------------ | -------------------- | --------------------------------- |
| StartTask02  | 遥控器初始化         | 无线遥控接收、遥控数据解析        |
| StartTask03  | 底盘电机 PID 控制    | 4个 3508 电机速度闭环控制         |
| StartTask04  | 云台 Yaw 控制        | 6020 电机角度控制、云台随动        |
| StartTask05  | 发射机构控制         | 摩擦轮 + 拨弹 + Yaw 补偿          |

---

## 🎮 核心功能

- ✅ **双板架构** — 底盘板 + 云台板通过 CAN 总线实时同步
- ✅ **RTOS 实时控制** — FreeRTOS 多任务精确调度
- ✅ **传感器融合** — BMI088 + IST8310 姿态解算
- ✅ **PID 闭环控制** — 位置/速度/力矩级联 PID
- ✅ **无线遥控** — 遥控器（RC）信号解析与映射
- ✅ **功率管理** — 底盘功率限制与缓冲能量监控
- ✅ **热量管理** — 枪管热量监控与射速限制
- ✅ **CAN 通信** — 低延迟板间通信

## 🚀 编译与烧录

### 环境要求

- **Windows**: Keil MDK-ARM 5.x
- **STM32CubeMX** (用于修改硬件配置)
- **STM32F4xx HAL 库** (已包含在 Drivers 目录中)

### 编译步骤

1. 使用 Keil µVision 打开对应的 `.uvprojx` 工程文件
2. 选择目标芯片：STM32F407xx
3. 点击 **Build (F7)** 编译工程
4. 编译输出 `.hex` 文件位于 `MDK-ARM/` 目录下

### 烧录

- 使用 **ST-Link** / **J-Link** 调试器连接开发板
- 在 Keil 中点击 **Download (F8)** 烧录固件

### 清理

- 运行 `keilkilll.bat` 清理中间编译文件

## ⚠️ 注意事项

- 本项目使用 **GBK** 编码，请用对应编码打开源文件
- 固件针对特定机械结构和电机配置，移植时需重新标定 PID 参数
- CAN 总线 ID 需与电调（ESC）配置一致
- 发射机构热控逻辑需根据裁判系统规则调整
